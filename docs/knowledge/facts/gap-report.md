## Where to start

1. The **behavioural** column is the one that matters for production. A route
   that is registered but answers the wrong shape is worse than a route that
   is absent, because a client cannot tell the difference.
2. The cheapest wins are the ones the replay already names: the Canvas response
   middleware (every case), JSON error bodies (402 cases), and body extraction
   that tolerates a missing Content-Type (45 cases).
3. The **column** gaps are mechanical and additive. The permissions gap needs a
   decision per permission — a port that silently allows what Canvas denies is
   a security defect, so it is not a bulk edit.
